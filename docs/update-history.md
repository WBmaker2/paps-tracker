# PAPS Tracker Update History

이 문서는 PAPS Tracker가 초기 MVP에서 현재 `v1.1.0` 운영 안정화 흐름까지 발전한 과정을 사용자와 개발자가 함께 확인할 수 있도록 정리한 업데이트 기록입니다.

## v1.1.0 - 보안과 운영 기반 강화

교사 접근과 기존 시트 승인 절차를 강화하고, 학생 제출 성능·접근성·CI·코드 구조를 함께 안정화했습니다.

- `GOOGLE_HOSTED_DOMAIN` 또는 `TEACHER_EMAIL_ALLOWLIST`가 없으면 교사 로그인을 허용하지 않는 fail-closed 정책을 적용했습니다.
- 기존 담당교사가 지정 이메일용 15분 승인 코드를 발급해야만 새 교사를 기존 시트에 추가할 수 있게 했습니다.
- 수동 동기화 대상도 현재 교사가 연결한 시트로 제한해 다른 시트 오지정 가능성을 차단했습니다.
- 학생 제출 뒤 2,000행 전체 요약을 다시 쓰지 않고 해당 학생·종목의 요약 행 하나만 갱신하도록 변경했습니다.
- Node.js 22를 고정하고 테스트, 린트, 운영 코드 타입 검사, 프로덕션 빌드를 실행하는 GitHub Actions CI를 추가했습니다.
- 접근성 대화상자·상태 알림·현재 메뉴 표시를 공통화하고, 설정 화면의 최초 연결 안내와 고급 진단을 접을 수 있게 단순화했습니다.
- 설정 카드와 학생 세션 조회·요약 저장 시트 서비스를 역할별 파일로 분리하고 README를 현재 운영 구조에 맞게 갱신했습니다.
- 교사가 현장에서 지도하는 기존 학생 입력 흐름은 유지하며 별도 학생 인증·만료 링크는 추가하지 않았습니다.

## v1.0.3 - 악력 좌우 기록

악력 측정을 오른쪽과 왼쪽으로 나누어 입력하고, 양손 각각의 최고 기록을 대표값으로 확인할 수 있게 개선했습니다.

- 학생 입력 화면에서 악력 종목은 오른쪽 악력과 왼쪽 악력을 따로 입력하도록 변경했습니다.
- 기존 기록 구조와 호환되도록 전체 기록값은 유지하면서 좌우 상세 기록을 함께 저장합니다.
- 학생 즉시 결과와 Google Sheets 요약에서 오른쪽 대표값과 왼쪽 대표값을 각각 표시합니다.

## v1.0.2 - 설정 저장 후 즉시 최신화

학교 정보를 저장한 뒤 새로고침하지 않아도 교사 PIN 상태와 학급 관리 목록이 최신 시트 정보로 바로 바뀌도록 개선했습니다.

- 학교 정보 저장 API가 연결된 시트의 학급 목록까지 함께 반환하도록 확장했습니다.
- 교사 화면 접근 PIN 설정 여부를 저장 직후 화면 상태에 즉시 반영하도록 수정했습니다.
- 기존 시트 연결 응답에서 PIN 해시 값은 숨기고 설정 여부만 내려주도록 안전하게 정리했습니다.

## v1.0.1 - 즉시 결과 기록 순서 보정

학생이 기록을 입력한 직후 누적 기록 표와 직전 대비 수치가 실제 측정 흐름에 맞게 표시되도록 안정화했습니다.

- 같은 세션 안의 여러 회차 기록은 저장 시각보다 회차 순서를 우선해 표시하도록 수정했습니다.
- 직전 대비 계산이 바로 이전 기록과 비교되도록 보정해 잘못된 향상 폭이 표시되는 문제를 해결했습니다.
- 소수 계산 오차가 화면에 길게 노출되지 않도록 직전 대비 값을 보기 좋은 숫자로 정리했습니다.

## v1.0.0 - 완제품 운영 흐름

교사 홈을 중심으로 학교 설정, 학생 명단, 세션 운영, 기록 입력, 결과 검토, Google Sheets 동기화까지 한 흐름으로 정리했습니다.

- 랜딩 페이지를 교사 시작 중심으로 정리하고 학생 입력은 세션 링크 또는 QR 안내 흐름으로 분리했습니다.
- 교사 홈에서 세션 생성과 상태 관리를 함께 처리하도록 대시보드와 세션 화면의 역할을 통합했습니다.
- 현재 안정화 상태를 `v1.0.0`으로 표시하고 업데이트 기록을 랜딩에서 바로 확인할 수 있게 했습니다.

## v0.9.0 - 자동 복구와 운영 안정화

구글 로그인 이후 이전에 저장한 학교와 시트 정보를 자동으로 불러오고, 시트 읽기 요청을 줄이는 방향으로 안정성을 높였습니다.

- 저장된 학교 정보와 Google Sheets 연결 정보를 교사 화면 진입 시 자동 복구하도록 개선했습니다.
- Smart Polling과 로컬 상태 반영으로 전체 새로고침 의존을 줄였습니다.
- Google Sheets API 쿼터 초과 가능성을 줄이도록 mutation 이후 부분 반영 흐름을 늘렸습니다.

## v0.8.0 - 교사 접근 제어

Google 로그인, 교사 허용 정책, 학생 화면의 교사 복귀 PIN을 조합해 교사용 화면 접근을 더 안전하게 만들었습니다.

- 교사 관리 영역 진입에 Google OAuth 흐름을 적용했습니다.
- 교사 이메일 허용 정책과 기존 시트 담당교사 등록 흐름을 보강했습니다.
- 학생 세션 화면에서 교사 관리 화면으로 돌아갈 때 PIN 안전장치를 추가했습니다.

## v0.7.0 - 학생별 성장 기록

한 학생의 지난 세션 기록까지 함께 모아 종목별 성장 추이를 표와 그래프로 확인할 수 있게 했습니다.

- 학생 입력 직후 결과 화면에서 이번 세션뿐 아니라 누적 기록을 함께 보여주도록 개선했습니다.
- 교사 결과 화면에 학생별 기록 조회와 종목별 성장 그래프를 추가했습니다.
- PAPS 데이터를 1년 동안 누적 관리하는 활용 흐름을 강화했습니다.

## v0.6.0 - 결과 검토와 동기화

측정 결과를 필터링하고 대표값을 선택한 뒤 Google Sheets 반영 상태를 확인하는 교사용 검토 흐름을 확장했습니다.

- 학년, 반, 종목, 세션 유형별 결과 필터를 추가했습니다.
- 대표값 선택과 수동 동기화 이후 로컬 상태가 즉시 반영되도록 개선했습니다.
- 동기화 실패 건수와 일부 동기화 메타 정보를 화면 상태에서 이어서 관리하도록 정리했습니다.

## v0.5.0 - 학생 입력 경험 개선

학생이 종목과 이름을 고르고 기록을 제출한 뒤 즉시 결과를 확인하고, 방금 입력한 기록을 수정할 수 있게 했습니다.

- 여러 종목 세션에서 학생이 오늘 측정할 종목을 선택할 수 있도록 했습니다.
- 기록 제출 후 다음 학생 버튼 없이 이름 버튼만 눌러도 다음 입력을 시작할 수 있게 개선했습니다.
- 입력 직후 실수한 기록을 바로 수정하는 기능을 추가했습니다.

## v0.4.0 - 세션 운영 고도화

단일 반과 2반 분할 운영, 여러 종목 선택, 세션 이름과 종목 수정 등 실제 수업 운영에 필요한 세션 기능을 넓혔습니다.

- 학년 구분 없이 두 개 반을 선택해 같은 종목을 함께 기록하는 2반 분할 운영을 지원했습니다.
- 세션 생성 시 여러 종목을 선택하고, 생성한 세션의 이름과 종목도 수정할 수 있게 했습니다.
- 최근 세션과 세션 상태 표시를 더 일관된 카드 흐름으로 정리했습니다.

## v0.3.0 - 학교, 학급, 학생 관리

교사가 학교 정보, 학급, 학생 명단을 웹앱에서 직접 등록하고 수정할 수 있는 관리 기능을 갖췄습니다.

- 학교명과 Google Sheets URL 저장 흐름을 만들고 저장 상태가 유지되도록 보강했습니다.
- 학년과 반 번호만으로 학급을 등록하도록 학급 관리 UI를 단순화했습니다.
- 학생 명단 추가, 학급별 필터링, 학생 정보 수정과 삭제 기능을 추가했습니다.

## v0.2.0 - Google Sheets 연동

교사 화면의 데이터가 Google Sheets에 저장되고, 시트의 변경 사항도 웹앱에 반영될 수 있도록 연동 기반을 마련했습니다.

- Google Sheets 템플릿, 서비스 계정 연결, 시트 검증 흐름을 추가했습니다.
- 학교, 학급, 학생, 세션, 기록 데이터를 시트 탭 구조에 맞춰 읽고 쓰도록 구성했습니다.
- 시트 동기화 상태와 재동기화 흐름을 교사 화면에서 확인할 수 있게 했습니다.

## v0.1.0 - 초기 MVP

PAPS 학생 기록 시스템의 기본 진입점과 교사·학생 역할 구분, 세션 입력 흐름의 뼈대를 만들었습니다.

- 랜딩 페이지에서 교사 관리 영역과 학생 입력 영역의 초기 구조를 제공했습니다.
- 교사용 대시보드와 학생 세션 입력 화면의 기본 형태를 구성했습니다.
- PAPS 측정 기록을 웹앱에서 빠르게 입력하고 확인하는 MVP 방향을 검증했습니다.
