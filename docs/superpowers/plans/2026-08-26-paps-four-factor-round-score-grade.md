# PAPS 체지방 제외 4요인 회차 점수·등급 구현계획

- 작성일: 2026-08-26
- 상태: 사용자 승인안 구현 및 격리 Google Sheets E2E 완료
- 규정 경계: 학교건강검사규칙의 공식 5요인 종합점수·등급이 아닌 프로젝트 자체 4요인 환산 결과

## 1. 승인된 목표

교사가 평가 회차를 만들고 학생이 다음 4개 체력요인의 측정을 마치면 학생별 회차 결과를 기록한다.

1. 심폐지구력
2. 유연성
3. 근력·근지구력
4. 순발력

체지방 측정, BMI 입력, 체지방 점수는 생성·측정·계산·등급 판정·결과 화면에서 모두 제외한다.

## 2. 결과 명칭과 교육적 경계

공식 PAPS 종합 체력등급은 체지방을 포함한 5개 요인을 기준으로 한다. 이 앱의 결과는 공식 결과와 혼동하지 않도록 다음 명칭을 사용한다.

- `체지방 제외 4요인 합계`: 0~80점
- `체지방 제외 환산점수`: 0~100점
- `체지방 제외 4요인 등급`: 1~5등급

화면과 내보내기에서 `공식 종합점수`, `공식 종합등급`이라는 표현을 사용하지 않는다.

## 3. 계산 계약

### 요인 점수

- 각 요인에서 선택한 한 종목의 대표 측정값을 공식 종목별 세부 기준으로 0~20점으로 환산한다.
- 현재 종목별 1~5등급을 합산하거나 평균 내지 않는다.
- 규칙 버전과 계산 출처를 결과에 저장한다.

### 4요인 합계와 환산점수

```text
fourFactorSubtotal = cardio + flexibility + strengthEndurance + power
normalizedScore = fourFactorSubtotal × 1.25
```

- `fourFactorSubtotal`: 정수 0~80
- `normalizedScore`: 0~100, 화면에서는 소수 첫째 자리까지 표시
- 원래 합계와 환산점수를 모두 저장하여 계산을 재현할 수 있게 한다.

### 등급

환산점수 기준:

| 환산점수 | 4요인 등급 | 4요인 합계의 동등 경계 |
|---:|---:|---:|
| 80~100 | 1등급 | 64~80 |
| 60~79.9 | 2등급 | 48~63 |
| 40~59.9 | 3등급 | 32~47 |
| 20~39.9 | 4등급 | 16~31 |
| 0~19.9 | 5등급 | 0~15 |

등급 함수는 부동소수점 반올림에 의존하지 않고 `fourFactorSubtotal`의 정수 경계로 판정한다.

### 미완료와 제외

- 4개 요인 중 하나라도 대표 기록이 없으면 점수와 등급을 만들지 않는다.
- 미측정을 0점으로 간주하지 않는다.
- 학생 전체가 평가에서 제외된 경우 `측정제외`로 기록하고 결과는 `null`로 둔다.
- 체지방은 애초에 요구 요인이 아니므로 `미측정`이나 `제외` 상태에도 포함하지 않는다.

## 4. 도메인 구조

### 체력요인

```ts
type PAPSFourFactorId =
  | "cardiorespiratory-endurance"
  | "flexibility"
  | "strength-endurance"
  | "power";
```

기존 종목 정의에 `factorId`를 추가한다.

- 심폐지구력: 왕복오래달리기, 오래달리기-걷기, 스텝검사
- 유연성: 앉아윗몸앞으로굽히기, 종합유연성
- 근력·근지구력: 윗몸말아올리기, 악력
- 순발력: 50m달리기, 제자리멀리뛰기

### 평가 회차

`PAPSAssessmentRound`를 추가한다.

- `id`, `name`, `academicYear`, `schoolId`, `teacherId`
- `roundType`: `regular | followUp`
- `roundNumber`
- `status`: `draft | open | review | finalized | archived`
- `classTargets`
- `selectedEventsByFactor`: 정확히 4개 요인
- `ruleVersion`
- 생성·개방·확정 시각

기존 `PAPSSession`은 종목별 실제 입력 단위로 유지하고 `assessmentRoundId`와 `factorId`로 회차에 연결한다. 기존 `sessionGroupId`는 과거 임의 종목 묶음으로 계속 지원하되 자동 변환하지 않는다.

### 학생별 회차 결과

`PAPSStudentRoundResult`를 추가한다.

- `roundId`, `studentId`, `revision`
- `status`: `incomplete | excluded | ready | finalized | stale`
- 학년·성별·반·번호 스냅샷
- 4개 요인의 종목 ID, 대표 시도 ID, 원 측정값, 요인 점수
- `fourFactorSubtotal`
- `normalizedScore`
- `fourFactorGrade`
- `ruleVersion`, `ruleSource`
- `calculatedAt`, `finalizedAt`, `finalizedBy`
- 이전 revision 연결

대표 시도나 원 측정값이 변경되면 기존 확정본을 덮어쓰지 않고 `stale`로 표시한다. 재확정 시 새 revision을 저장한다.

## 5. 교사 화면

### 회차 생성

- 생성 유형을 `4요인 평가 회차`와 `종목 기록·연습`으로 분리한다.
- 4요인 회차에는 네 개의 요인 카드를 고정 표시한다.
- 각 요인에서 정확히 한 종목만 선택할 수 있다.
- 대상 반의 모든 학년에 적격한 종목만 활성화한다.
- 체지방/BMI 항목은 만들지 않는다.

### 결과 검토

- 학생×4요인 완료 매트릭스를 제공한다.
- 대표 시도와 요인별 0~20점을 검토한다.
- 4요인 합계, 환산점수, 4요인 등급 미리보기를 제공한다.
- 모든 조건이 충족된 학생만 `4요인 결과 확정`을 활성화한다.
- 확정 버튼에는 `gi-pulse` 아우라를 적용하고 reduced-motion에서는 정적 강조로 대체한다.

## 6. 학생 화면

- 학생 선택 후 네 요인의 `완료/미측정` 진행상태를 보여준다.
- 저장 후 `다음 미측정 종목` 버튼을 주요 행동으로 제공하고 `gi-pulse` 아우라를 적용한다.
- 다른 학생의 누적 이력은 노출하지 않는다.
- 교사 확정 전에는 최종 점수·등급을 표시하지 않는다.
- 확정 후 다음을 표시한다.
  - 4개 요인의 대표 기록과 점수
  - 4요인 합계 0~80
  - 체지방 제외 환산점수 0~100
  - 체지방 제외 4요인 등급
  - `공식 PAPS 종합등급이 아닌 체지방 제외 4요인 환산 결과입니다.` 안내

## 7. API

- `POST /api/assessment-rounds`: 4요인 회차 생성
- `GET /api/assessment-rounds/:id`: 회차·진행상태 조회
- `POST /api/assessment-rounds/:id/preview`: 최신 대표값으로 미리보기
- `POST /api/assessment-rounds/:id/students/:studentId/finalize`: 학생 결과 확정
- `POST /api/assessment-rounds/:id/finalize-ready`: 준비 학생 일괄 확정
- `POST /api/assessment-rounds/:id/students/:studentId/exclude`: 학생 측정제외

확정 API는 클라이언트 점수를 신뢰하지 않고 최신 원자료를 다시 읽어 서버에서 계산한다. revision이 일치할 때만 멱등 저장한다.

## 8. Google Sheets

새 탭 `4요인회차결과`를 추가한다.

주요 열:

- 회차 ID, 학생 ID, revision, 상태
- 학년도, 회차 유형, 회차 번호
- 학생 기준정보 스냅샷
- 4개 요인의 종목/대표 시도/원 측정값/점수
- 4요인 합계, 환산점수, 4요인 등급
- 규칙 버전·출처
- 계산·확정 시각, 확정 교사, 이전 revision

시트 템플릿 버전을 올리고 이전 시트에는 안전한 탭·헤더 보강을 제공한다. 기존 세션 기록과 요약 탭은 유지한다.

## 10. 테스트 기준

- 모든 지원 학년·성별·종목의 0~20점 경계
- 4요인 합계 `15/16`, `31/32`, `47/48`, `63/64`
- 환산점수 `합계 × 1.25`
- 한 요인 누락 시 점수·등급 `null`
- 체지방 없이 회차 생성과 확정 성공
- 체지방/BMI 필드가 API·시트·화면에 존재하지 않음
- 분할 반의 모든 학년에서 종목 적격성 검증
- 대표값 변경 후 `stale` 및 새 revision
- 확정 API 멱등성과 동시 수정 충돌
- 기존 단일/다종목 세션 회귀 없음
- 학생이 타 학생 누적 기록을 볼 수 없음
- 390×812 모바일, 키보드, 오류 포커스, reduced-motion
- Node 22에서 테스트·린트·타입검사·빌드 통과

## 11. 완료 기준

- 4개 요인에서 각각 한 종목을 선택하지 않으면 회차를 만들 수 없다.
- 네 대표 기록이 모두 있어야 점수와 등급을 계산·확정한다.
- 체지방 측정과 점수는 어떤 결과에도 요구되거나 포함되지 않는다.
- 결과는 항상 `체지방 제외 4요인`임을 표시한다.
- 계산 결과가 규칙 fixture와 재현 가능하게 일치한다.
- 확정본에 대표 시도·학생 스냅샷·규칙 버전·revision이 저장된다.
- 기존 기능과 시트 데이터가 보존된다.
- 앱의 업데이트 내역에 2026-08-26 개선 내용을 추가한다.

## 12. 실 Google Sheets E2E 회귀 수정 계획

2026-08-26 격리 테스트 시트에서 첫 종목 제출 API는 `201`로 성공했지만, 제출 직후 학생 진행 카드가 `roundProgress.factors.map is not a function`으로 중단되었다.

원인은 로컬/초기 화면 계약이 진행 요인을 배열로 제공하는 반면 Google Sheets 제출 어댑터가 같은 필드를 `factorId` 키 객체로 반환한 계약 불일치다. 최종 확정 결과의 `factors`는 기존 키 객체 계약을 유지하고, 진행상태의 `factors`만 다음 순서로 배열로 통일한다.

1. `PAPSStudentRoundSubmitProgress.factors` 타입을 4개 진행 항목 배열로 변경한다.
2. Google Sheets 제출 응답과 로컬 제출 응답을 같은 배열 형태로 생성한다.
3. Google Sheets 어댑터 회귀 테스트에 배열 형태와 4요인 순서를 고정한다.
4. 관련 단위 테스트·타입검사·빌드를 통과시킨다.
5. 격리 시트에서 네 종목 제출, 교사 확정, 최종 4요인 점수·등급 저장까지 다시 검증한다.

## 13. 학생 확정 결과 재조회 보강 계획

교사 확정과 시트 저장 후 학생 세션을 새로 열면 공용 초기 화면이 학생별 결과를 조회하지 않아 0/4로 돌아가고 확정 결과도 보이지 않는 E2E 결함이 확인되었다.

개인정보 경계를 유지하기 위해 전체 학생 결과를 페이지에 포함하지 않고 다음처럼 보강한다.

1. 서명된 세션 그룹 접근 토큰, 세션 그룹 ID, 선택 학생 ID를 모두 검증하는 읽기 전용 API를 추가한다.
2. API는 해당 그룹 대상 반의 선택 학생 1명에 대해서만 진행상태와 확정 결과를 반환한다.
3. 학생 이름 선택 시 이 API를 호출해 4요인 진행과 확정 결과 카드를 복원한다.
4. 누적 시도 이력이나 다른 학생 결과는 응답하지 않는다.
5. UI 회귀 테스트와 실 Google Sheets E2E에서 확정 결과 재열람을 검증한다.

## 14. 격리 Google Sheets E2E 완료 결과

- 가상 학교·학급·학생만 포함한 일회성 시트에서 4요인 회차 전체 흐름을 완료했다.
- 요인 점수 `19/20/16/20`, 합계 `75/80`, 환산점수 `93.75/100`, `1등급`이 미리보기·확정 저장·학생 재조회에서 일치했다.
- 결과 저장 열에 체지방·BMI 측정 항목이 없고, 결과 문구는 공식 PAPS 종합등급과 구분된다.
- 전체 테스트 72개 파일·326개, 린트, 타입 검사, 프로덕션 빌드가 통과했다.
- 검증 후 테스트 시트는 Google Drive 휴지통으로 이동하고 신규 임시 서비스 계정 키는 폐기했으며 기존 키는 보존했다.
