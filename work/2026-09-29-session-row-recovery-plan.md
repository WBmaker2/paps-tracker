# 9월 5·6학년 세션 설정 행 손상 복구 계획

## 확인된 상태

- 기준 커밋 `7222302`는 `설정` 탭의 고정 200행 쓰기 제한을 제거했다. 운영 배포 여부와 운영 시트 복구는 별개다.
- 운영 `설정` 탭은 200행에서 끝난다. 대상 묶음의 `제자리멀리뛰기` 묶음 항목은 있으나 세션 행은 없고, `악력` 세션은 대상 학급 행이 없다.
- 운영 `세션기록` 318행에서 이 두 하위 세션 ID로 연결된 측정 기록은 0건이었다. 이 확인은 2026-09-29 읽기 전용 스냅샷이다.

## 구현 범위

1. 설정 탭 쓰기 뒤 실제 행을 재조회하고, 요청한 세션·묶음·대상 학급 행이 보존됐는지 검증한다. 불완전한 쓰기는 성공 응답을 보내지 않는다.
2. 200행 경계(기존 200행, 새 208행)를 넘는 왕복 테스트와 묶음 항목만 남거나 대상 학급이 빠진 손상 테스트를 추가한다.
3. 운영 시트의 해당 묶음만 복구할 수 있는 좁은 도구를 만든다. 기본은 읽기 전용 진단·미리보기다. 실행 모드는 백업 스냅샷, 정확한 시트 ID·묶음 ID·행 상태 재확인, 측정 기록 보존, 복구 후 재조회를 요구한다. 다른 세션과 학생 데이터를 다시 쓰지 않는다.
4. 앱 업데이트 내역에 사용자에게 보이는 변경을 간단히 기록한다. 코드 파일은 500줄 미만으로 유지한다.

## 검증과 운영 경계

- 관련 단위·왕복 테스트, 타입 검사, 린트, 빌드를 수행한다. 기존 작업 공간의 다른 변경은 건드리지 않는다.
- 운영 시트의 실제 쓰기와 앱 배포는 이 구현 검증 결과를 검토한 뒤 진행한다. 지금은 운영 시트에 쓰지 않는다.
- 복구 시 제자리멀리뛰기 세션의 원래 ID와 악력의 두 학급 연결을 되살리고, 학생 화면에서 네 종목 및 각 이름판을 확인한다.
