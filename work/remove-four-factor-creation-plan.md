# 교사 세션 생성의 4요인 평가 회차 제거 계획 — 2026-09-29

## 요청 범위

- 교사 홈의 `세션 생성`에서 `4요인 평가 회차` 선택 항목을 제거합니다.
- 선택 항목에만 쓰이던 4요인 생성 입력과 제출 분기를 제거하여 종목 세션 생성 폼을 단일 흐름으로 만듭니다.
- 기존에 생성된 평가 회차, 학생 기록, 교사 결과 조회와 관련 API·Google Sheets 행은 변경하거나 삭제하지 않습니다.

## 구현 및 검증

1. `SessionForm`의 생성 모드 상태·전용 입력·`/api/assessment-rounds` 제출 분기를 제거합니다. 종목 기록·연습의 생성·수정 흐름은 유지합니다.
2. 선택 카드만 남지 않도록 `SessionCreationModeFieldset`와 더 이상 사용하지 않는 생성 전용 컴포넌트를 정리합니다. 기존 회차 결과 컴포넌트는 유지합니다.
3. 기존 4요인 생성 UI 테스트를 제거된 항목 부재와 일반 세션 생성 회귀 검증으로 바꾸고, 기존 회차 결과·학생 진행 테스트는 유지합니다.
4. 업데이트 내역과 앱 버전을 v1.2.5로 갱신하고, 모든 변경 코드 파일을 500줄 미만으로 유지합니다.
5. Node 22에서 전체 테스트, lint, 타입 검사, 빌드, 운영 의존성 감사와 diff 검사를 통과시킵니다.
6. 이전 턴에서 승인받은 커밋·푸시·프로덕션 배포 흐름으로 릴리스하고, Ego Browser에서 교사 화면을 읽기 전용으로 확인합니다. 운영 Google Sheets에는 쓰지 않습니다.
